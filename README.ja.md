# Wyrly DI（日本語）

利用者向けドキュメントの日本語版です。

- **Examples 一覧**: [examples/README.ja.md](examples/README.ja.md)
- **メインドキュメント（英語）**: [README.md](README.md)

ランタイムメッセージの表示言語は実行環境（`LANG`、`WYRLY_LOCALE` など）から自動判定されます。`container.validate({ locale: "ja" })` などで指定できます。

`wyrly` CLI（doctor / graph / validate / generate）は **Wyrly Pro**（非公開・商用）です。この OSS リポジトリには含まれません。
