# express-api

Lightweight REST example with `@wyrly/express` `diMiddleware` and request scope.

Japanese: [README.ja.md](./README.ja.md)

## Run

```sh
deno task example:express-api
```

Requires `net` (`127.0.0.1` listen + fetch).
