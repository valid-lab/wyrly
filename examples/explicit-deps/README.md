# explicit-deps

Register dependencies with `register({ deps: [...] })` only — no decorators.

Japanese: [README.ja.md](./README.ja.md)

## What you learn

- Explicit provider registration without `@Injectable`
- Same resolution model as constructor injection

## Run

```sh
deno task example:explicit-deps
```
