# provider-patterns

`useValue` / `useFactory` / `useExisting` の 3 パターンを 1 つの composition root で示します。

## 学ぶこと

- 定数・設定値の `useValue`
- scope 付き `useFactory`
- エイリアス登録の `useExisting`

## 実行

```sh
deno task example:provider-patterns
```
