Wyrly is open source.

If it helps your project, the most useful support right now is trying it in a real project,
sharing feedback, improving documentation, or contributing examples.

## Sponsor the project

Sponsorship is not set up yet.

Sponsorship links may be added later if there is enough usage and maintenance demand.
For now, feedback and concrete adoption blockers are more helpful than financial support.

## Contribute

You can also support Wyrly by contributing:

- bug reports with minimal reproductions
- documentation improvements
- framework examples
- adapter fixes
- migration guides from other DI libraries
- feedback on API ergonomics

Start with [Contributing](/contributing/overview).

## Share feedback

Open an issue or discussion in the GitHub repository:
