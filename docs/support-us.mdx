Wyrly is open source.

If it helps your project, you can support the work by contributing code, improving documentation,
sharing feedback, or sponsoring the maintainers.

## Sponsor the project

Sponsorship links will be added here as they become available.

Potential sponsorship channels:

- GitHub Sponsors
- Open Collective
- Polar

## Contribute

You can also support Wyrly by contributing:

- bug reports with minimal reproductions
- documentation improvements
- framework examples
- adapter fixes
- migration guides from other DI libraries
- feedback on API ergonomics

Start with [Contributing](/contributing/overview).
