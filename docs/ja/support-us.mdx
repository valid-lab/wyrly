Wyrly は open source です。

もし project で役に立ったら、今最も助かる支援は、実際の project で試すこと、feedback
を共有すること、documentation を改善すること、examples を追加することです。

## Sponsor the project

Sponsorship はまだ設定していません。

利用が増え、maintenance demand が十分に見えてきたら、後から sponsorship links を追加する可能性があります。
今は financial support より、feedback と具体的な adoption blockers の共有がより役に立ちます。

## Contribute

次のようなコントリビューションも Wyrly の支援になります。

- 再現手順付きのバグ報告
- ドキュメントの改善
- フレームワーク向けのサンプル
- アダプターの修正
- 他の DI ライブラリからの移行ガイド
- API の使い勝手へのフィードバック

まずは [Contributing](/ja/contributing/overview) から始めてください。

## Share feedback

GitHub repository で issue または discussion を開いてください。
