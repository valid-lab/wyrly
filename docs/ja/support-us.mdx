Wyrly は open source です。

もしプロジェクトで役に立ったら、今最も助かる支援は、実際のプロジェクトで試すこと、フィードバックを共有すること、ドキュメントを改善すること、サンプルを追加することです。

## Sponsor the project

Sponsorship はまだ設定していません。

利用が増え、メンテナンスの需要が十分に見えてきたら、後からスポンサーリンクを追加する可能性があります。
今は金銭的な支援より、フィードバックと具体的な導入障壁の共有がより役に立ちます。

## Contribute

次のようなコントリビューションも Wyrly の支援になります。

- 再現手順付きのバグ報告
- ドキュメントの改善
- フレームワーク向けのサンプル
- アダプターの修正
- 他の DI ライブラリからの移行ガイド
- API の使い勝手へのフィードバック

まずは [Contributing](/ja/contributing/overview) から始めてください。

## Share feedback

GitHub repository で issue または discussion を開いてください。
