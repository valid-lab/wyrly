Wyrly DI は、明示的で解析しやすく、型安全なアプリケーションアーキテクチャのための
依存性注入ツールキットです。

レガシーな decorator metadata、自動的な runtime type guessing、framework lock-in
なしで、モダン TypeScript アプリに DI を導入したいときに使います。

## Wyrly が向いている用途

Wyrly は、明確な composition root、明示的な依存関係、framework に依存しない domain
code を重視する TypeScript アプリケーション向けに設計されています。

特に DDD や Clean Architecture と相性がよく、use case は port に依存し、外側の layer
で typed token を通じて具体的な infrastructure を wiring します。

## 中核となる考え方

- `reflect-metadata` なし
- `emitDecoratorMetadata` なし
- parameter decorators なし
- Type-safe tokens
- 明示的な依存定義
- Singleton、scoped、transient lifetimes
- Web framework 向け request scopes
- inspection と validation が可能な dependency graph

## Packages

| Package | Purpose |
| --- | --- |
| `@wyrly/core` | Core container、typed tokens、lifetimes、validation、graph inspection |
| `@wyrly/next` | Next.js App Router request-scoped DI |
| `@wyrly/express` | 1 request につき 1 DI scope を作る Express middleware |
| `@wyrly/hono` | Edge-friendly な DI scope を作る Hono middleware |
| `@wyrly/fresh` | Fresh 2.x middleware と route helpers |
| `@wyrly/graphql` | GraphQL request context integration |
