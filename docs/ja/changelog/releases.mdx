Wyrly packages は `1.0.0` から Semantic Versioning に従います。

## バージョニング方針

- Major: 文書化された公開シンボル、シグネチャ、実行時の挙動の削除または破壊的変更
- Minor: 新しいエクスポートまたは後方互換性のある追加
- Patch: API 変更を伴わないバグ修正

Stable public API surface は [Public API](/ja/reference/public-api) に記載しています。

## v2.0.0

Wyrly DI v2.0.0 は現在の stable release line です。

Highlights:

- standard-decorator-first DI model
- typed tokens
- singleton、scoped、transient lifetimes
- request scopes
- dependency graph inspection
- graph と lifetime issues の validation
- Next.js、Express、Hono、Fresh、GraphQL 向け framework adapters
